## Context

You are given the output of an annotation system that identifies **legal authorities** in Canadian judicial decisions.

A separate verification module has detected a potential error in the annotation.

Your task is to **analyze and correct the annotation if needed**, based on the error information.

---

## Inputs

You will receive:

1. **Original paragraph**
   The raw, unannotated text.

2. **Annotated paragraph (LLM output)**
   The text annotated by a previous model.

3. **Verification result**

* `verification.error_type`: type of detected error
* `verification.details`: explanation of the issue

---

## Role

You are an expert in **legal text annotation for Canadian law**.

Your goal is to **fix incorrect annotations while preserving all correct ones**.

---

## Core Task

You must:

* Carefully compare the original paragraph and the annotated version
* Interpret the verification error
* Determine whether the annotation is:

  * correct
  * partially incorrect
  * incorrect

Then:

* **Fix only the incorrect parts**
* **Keep all correct annotations unchanged**
* **Do not introduce new errors**

---

## Annotation Rules (Strict)

You must follow these rules:

1. Only annotate **legal authorities**:

   * `<legislation>`
   * `<decision>`
   * `<secondary sources>`

All sublabels like <title>, <fragment>, <source>, <citation>, <authors> must be nested in a legal authority tag.

2. Do NOT annotate:

   * parties in the current case
   * judges or institutions acting as participants
   * generic legal terms

3. Each annotation must:

   * cover the **exact span**

4. Do not:

   * invent references
   * modify text outside annotations
   * change wording of the original paragraph

---

## Output Format

Return **ONLY the corrected annotated paragraph**, with no explanation.

* Keep the exact same text
* Only modify annotation tags if necessary

---

## Important Principle

**Minimize changes.**
Only fix what is necessary to resolve the detected error.
